# RealmeInfoBot — Reborn\n\nThe new independently controlled RealmeInfoBot. It talks directly to **RealmeBot API v2** and is designed to be deployed as a long-running Deta Space micro.\n\n## What it does\n- Interactive `/start` menu\n- Device lookup by name, codename, or RMX model\n- Search with ranked API results\n- Series browsing\n- Database statistics\n- OTA adapter\n- `/about` runtime/API status\n- Direct text search in private chats\n- Telegram command registration at startup\n- Long polling with automatic webhook cleanup\n- Telegram rate-limit retry handling\n- API retry/cache handling\n- Health endpoint for hosting\n- Graceful shutdown\n- HTML escaping for user/API data\n\n## Commands\n- `/start`\n- `/help`\n- `/menu`\n- `/whatis <device>`\n- `/codename <device>`\n- `/deviceinfo <device>`\n- `/search <query>`\n- `/series <series>`\n- `/devices`\n- `/ota <device>`\n- `/about`\n\nIn a private chat, sending a device name such as `GT Neo 3`, `lisaa`, or `RMX3560` directly performs a search.\n\n## Runtime variables\nRequired:\n- `TELEGRAM_BOT_TOKEN`\n- `REALME_API_URL`\nOptional:\n- `OTA_API_URL`\n- `BOT_NAME`\n- `BOT_VERSION`\n- `PORT`\n- `HEALTH_PORT`\n\n## Local run\n```bash\ncd bot\nnpm run check\nTELEGRAM_BOT_TOKEN="..." REALME_API_URL="http://localhost:8080" npm start\n```\n\n## GitHub Actions deployment\nThe repository contains `.github/workflows/deploy-bot.yml`.\n\nIt validates the bot and then deploys the `bot/` directory to Deta Space on pushes to `main` that touch the bot.\n\nCreate these GitHub Actions secrets:\n- `BOT_SPACE_ACCESS_TOKEN`\n- `BOT_SPACE_PROJECT_ID`\n\nThe bot's runtime environment variables must also be configured in the Deta Space project:\n- `TELEGRAM_BOT_TOKEN`\n- `REALME_API_URL`\n- `OTA_API_URL` (when available)\n\nThe GitHub Action is only responsible for publishing the code. Runtime secrets should not be committed to the repository.\n\n## Health\n`GET /` and `GET /health` return a small JSON status document. This keeps the micro externally observable while Telegram updates are received through long polling.
